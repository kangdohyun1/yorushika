# 夜しか — 요루시카 서재

요루시카 팬이 개인적으로 쓰려고 만든 비공식 앱입니다. 곡·앨범·이야기의 권리는 요루시카와 각 권리자에게 있으며, 이 저장소에는 가사나 음원이 들어 있지 않습니다.

## 휴대폰에 설치 (안드로이드 앱)
1. 휴대폰으로 **[Releases → 최신 버전](../../releases/latest)** 열기
2. `yorushika-v1.0.N.apk` 눌러 받기 → 열기 → 설치
   - "출처를 알 수 없는 앱" 경고가 나오면 이번만 허용
3. 앱 실행 → 설정 → 음원 가져오기 → "새 발매 알림 받기"

안드로이드 앱은 최근 앱 목록에서 밀어 꺼도 재생이 이어지고, 잠금화면·알림창·버즈로 조작할 수 있습니다.
새 버전이 올라오면 앱 설정에 표시되며, 같은 방법으로 덮어 설치하면 됩니다(데이터 유지).

## 웹 버전 (PC)
Settings → Pages → Branch `main`, 폴더 `/docs` 로 켜면
`https://kangdohyun1.github.io/yorushika/` 에서 열리고, Chrome·Edge에서 앱으로 설치할 수 있습니다.

## 구조
- `docs/` — 웹앱 (PWA). 안드로이드 앱에도 그대로 들어갑니다.
- `android/` — 안드로이드 앱 (WebView + Media3 재생 서비스 + 새 발매 확인 작업)
- `.github/workflows/android.yml` — `main`에 올릴 때마다 APK를 빌드해 Releases에 올립니다.
